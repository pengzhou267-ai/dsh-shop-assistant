# 客服话术

1. 先确认问题类型：售前咨询 / 订单物流 / 退换货 / 投诉安抚。
2. 阅读知识库目录中的 `售后政策.md`（路径见系统提示），**禁止编造**店铺没有的承诺。
3. 若用户提供了订单/评价 CSV，先调用 `shop_csv_preview` 核对事实，再写回复。
4. 输出格式：
   - 场景标签
   - 推荐回复（可复制）
   - 备选短句 ×2
   - 需要人工介入的情况（若有）
5. 语气礼貌、简短；不攻击买家；不确定的物流信息写「请提供订单号，我帮您查」。
