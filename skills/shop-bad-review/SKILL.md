# 差评回复

1. 用 `shop_csv_preview` 读取评价表（adapter 可选 `taobao-review` / `pdd-review`）。
2. 按原因分组：质量 / 物流 / 描述不符 / 尺码 / 服务态度 / 其他。
3. 每组输出：共情一句 + 解决动作（退换/补发/优惠，必须符合知识库政策）+ 邀请私信订单号。
4. 禁止：否认事实、嘲讽买家、承诺政策外赔偿。
5. 最终给「可直接粘贴」的回复列表，按订单号或行号索引。
