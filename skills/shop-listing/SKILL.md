# Listing 文案

1. 若有竞品链接，先 `shop_page_snapshot` 提取标题/卖点/价格线索。
2. 向用户确认：平台（淘宝/拼多多/Shopify 等）、核心卖点、禁词。
3. 输出：
   - 标题候选 ×5（标注字数）
   - 五点描述
   - 详情页大纲（痛点→方案→参数→售后）
   - FAQ ×5
4. 不抄袭竞品原文；价格与库存以用户提供为准。
