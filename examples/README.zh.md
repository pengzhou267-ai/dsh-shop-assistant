# examples/ — 示例表格说明

这些文件是**假数据**，用来跟 README 里的三个案例练手。  
正式使用时，请换成你从平台后台导出的真实文件（建议 UTF-8 的 CSV）。

## 评价表：`reviews.csv`

| 列名 | 含义 | 示例 |
|------|------|------|
| 订单号 | 订单编号 | O1001 |
| 评分 | 星级 1～5 | 2 |
| 评价内容 | 买家原文 | 物流太慢了等了一周才到 |
| 评价时间 | 日期 | 2026-08-01 |
| SKU | 规格/货号（可选） | SKU-红-M |

把你的导出表另存为 CSV 后，列名尽量接近上表（淘宝常见「评价内容」「评分」等也可以，聊天里说明「按淘宝评价表识别」即可）。

放到工作区后可改名为 `评价.csv`，提示词里写这个文件名。

## 选品数字：`score-inputs.csv`

供案例 3 参考：成本、售价、竞品价，以及需求/竞争/运营难度/风险/时机（均为 1～5 分）。  
也可以不放文件，直接在聊天里口述这些数字。
